# Sistema de registro de masctoas en Vet.
#Como se usa:
 1.para depurar/ejecutar: se usa (ctrl+F5) para iniciar SIN depurar, (F5) para iniciar con depuracion. 
 2. Escriba "1" para ingresar mascota. 
 3. Ingrese nombre, especie y peso.
 4. Para listar las mascotas ingresadas escriba "2".
 5. Para buscar mascotas por especia escriba "3".
 6. Escriba "4" para salir y dar por finalizado.
